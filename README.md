# Deskripsi Singkat
Aplikasi vila permai merupakan aplikasi yang berbasis web untuk pemesanan tamu yang ingin menginap di daerah kawasan Puncak, Kabupaten Bogor.

# Cara Menjalankan Halaman
1. Clone repository(menyalin seluruh proyek dari jarak jauh untuk disimpan di komputer lokal) atau bisa diunduh folder ZIP.
2. Buka folder ZIP di komputer lali buka file index.html bisa menggunakan chrome,edge,dan lainnya.


# Fitur Utama
1. Daftar Pilihan Vila: Ada Katalog Vila yang membuat tamu bisa melihat sebelum membooking vila.
2. Pencarian: Tamu bisa mengetik di search bar ada vila apa saja dan tipe nya seperti apa.
3. Formulir Pemesanan: Tamu wajib mengisi dengan ketentuan pemesanan.
4. Cek Ketersedian & biaya: Sebelum memesan Tamu bisa terlebih dahulu mengecek estimasi biaya dan hari serta tersedian nya vila.
5. Pesan Sekarang & rincian booking: Jika tamu sudah yakin pesanannya bisa di klik pesan sekarang nanti akan diarahkan konfirmasi kepada pemilik vila via WhatsApp.
6. Penyimpanan: Data menyimpan nama tamu agar otomatis formulir dapat diisi kembali jika halaman dimuat ulang.
